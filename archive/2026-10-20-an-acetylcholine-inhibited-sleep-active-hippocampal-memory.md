# An acetylcholine-inhibited sleep-active hippocampal interneuron orchestrates memory consolidation

- **原标题**: An acetylcholine-inhibited sleep-active hippocampal interneuron orchestrates memory consolidation
- **作者**: Yili Feng, Qingli Dai, Xiang Fei, Haiqiong Yang, Tao Jiang
- **来源**: Neuron
- **发表日期**: 2026-10-20
- **原文**: [https://www.cell.com/neuron/fulltext/S0896-6273(26)00741-5?rss=yes](https://www.cell.com/neuron/fulltext/S0896-6273(26)00741-5?rss=yes)

## 一句话结论
大脑里有一类'睡眠专属'神经元，睡眠时靠关闭乙酰胆碱来启动记忆整理。

## 通俗解读
背景：睡眠对长期记忆很重要，但机制不清楚。方法：研究者记录小鼠海马体（大脑的记忆中枢）里一类特殊抑制性神经元的活动，并人为开、关它们。发现：这类神经元只在深度睡眠（NREM）时活跃，它们被乙酰胆碱抑制，活跃时会触发'海马涟漪'（大脑回放记忆的快速电波）。意义：睡眠不是被动休息，而是一套被精确开关控制的记忆写入程序，为改善记忆和睡眠干预提供了靶点。

## 关键方法
用光遗传学给特定神经元装一个光开关，随开随关，再看行为变化。相当于给电路里的某个电阻接一个遥控开关，观察整条线路的输出。
