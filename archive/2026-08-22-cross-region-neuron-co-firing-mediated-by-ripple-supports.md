# Cross-region neuron co-firing mediated by ripple oscillations supports distributed working memory representations

- **原标题**: Cross-region neuron co-firing mediated by ripple oscillations supports distributed working memory representations
- **作者**: Eric Halgren
- **来源**: Nature Neuroscience
- **发表日期**: 2026-08-22
- **原文**: [https://www.nature.com/articles/s41593-026-02403-z](https://www.nature.com/articles/s41593-026-02403-z)
- **AI 评分**: 7.1 / 10  (论文属于认知科学（探索领域）且涉及神经机制，对理解记忆与AI关联有启发，摘要概念虽抽象但可类比解释，适合做成科普内容。)

## 一句话结论
大脑跨脑区同步90Hz振动让记忆更牢固，像WiFi同步传输。

## 通俗解读
背景：大脑不同区域如何协同工作以记住信息一直是个谜。方法：研究人员记录人类大脑两侧多个区域神经元的活动，让受试者完成记忆任务。发现：当大脑两侧区域同时以90Hz频率振动时，神经元同步放电，并重现与记忆相关的活动模式，就像两座城市通过同步信号塔传递信息。意义：这种同步可能是大脑实现远距离整合的机制，有助于理解记忆和认知障碍。

## 关键方法
使用颅内脑电记录（iEEG）同时监测多个脑区，分析神经元放电与局部场电位（LFP）的相位关系，并比较不同记忆状态下的同步性。
