# Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation

- **原标题**: Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation
- **作者**: Bingxin Xu, Yuzhang Shang, Zhen Dong, Emilio Ferrara
- **来源**: arXiv
- **发表日期**: 2026-09-17
- **原文**: [https://arxiv.org/abs/2609.20822v1](https://arxiv.org/abs/2609.20822v1)
- **AI 评分**: 8.1 / 10  (论文属于AI+机器人核心领域，讨论编码智能体的安全约束规划，与用户关注的AI工程和自动化工作流高度相关。概念清晰（路线规划+接触执行比喻），安全优先的规划思路可迁移到自动化工作流设计和投资风险博弈中。)

## 一句话结论
会写代码的 AI 机器人会干活但容易撞到障碍物，加个'安全外挂'就能既干活又不撞。

## 通俗解读
背景：现在有人让大模型直接给机器人写代码控制它动作，不用专门训练，很灵活。但没人问过：这样安全吗？方法：研究者给机器人出难题——既要完成任务，又不能碰到障碍物。结果发现 AI 大多会撞上去，因为它满脑子只想'把活干完'，安全规则根本排不上优先级——不是没看见障碍物，也不是指令没说清，是规划时压根没把它当回事。于是作者做了个叫 SafeHarness 的'外挂'：走路前先画好绕开障碍物的路线并检查，接触物体时也特意选个不会碰到障碍物的位置。意义：加了外挂后，任务成功率 71.9%，避障率 87.5%，比之前最好的方法分别高了 6.5% 和 27%，是不加外挂时的 2.3 倍和 1.5 倍。

## 关键方法
把机器人动作拆成两步：一是'走路'，先让模型把物体框成方框，在方框上画一条由几个点连成的候选路线，规划完自己检查一遍，不行就重来，确认安全再走；二是'接触'，选一个不会碰到障碍物的位置去接触物体。相当于给 AI 配了个'安全副驾驶'，强制它先规划、再验证、最后执行。

## 对你的启发

- **程序员视角**: 做 AI Agent 时，光给 system prompt 写'别碰 XX'没用，模型会为了完成主任务忽略约束。得把约束变成可执行、可验证的结构化步骤（就像 SafeHarness 的路线规划+验证+重规划），在流程里强制执行，而不是靠一句提醒。
- **投资视角**: 说明'通用大模型直接控机器人'还早，安全约束是硬伤。短期内'给 Agent 加安全外挂/中间层'这类工程能力会是刚需，对应 AI 基础设施和 Agent 工具链的机会，值得关注谁在解决'约束优先级'问题。
- **内容视角**: 钩子：'我让 AI 写代码开机器人，结果它为了完成任务直接把障碍物撞飞了——AI 不是不懂安全，是根本不把安全当回事。'然后用这个实验讲清楚：给 AI 加约束，光说没用，得让它'先规划、再验证、最后执行'才行。
